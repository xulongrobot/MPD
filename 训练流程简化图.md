## 核心训练迭代详细流程

```
每次迭代 (train_steps_current):
│
├─> 1. 数据加载
│   └─> DataLoader 提供 batch_dict
│       • control_points_normalized
│       • hard_conds
│       • context_qs (可选)
│       • ee_pose_goal (可选)
│
├─> 2. 前向传播计算损失
│   │
│   ├─> loss_fn(model, batch_dict, dataset)
│   │   │
│   │   ├─> GaussianDiffusionLoss.loss_fn()
│   │   │   │
│   │   │   └─> diffusion_model.loss()
│   │   │       │
│   │   │       ├─> 随机采样时间步 t ~ U[0, n_steps]
│   │   │       │
│   │   │       └─> p_losses(x_start, context_d, t, hard_conds)
│   │   │           │
│   │   │           ├─> q_sample() - 添加噪声
│   │   │           │   x_t = sqrt(α_t) * x_0 + sqrt(1-α_t) * ε
│   │   │           │
│   │   │           ├─> apply_hard_conditioning() - 应用硬约束
│   │   │           │
│   │   │           ├─> context_model() - 编码上下文
│   │   │           │   └─> ContextModelCombined
│   │   │           │       ├─> ContextModelQs → MLP编码
│   │   │           │       └─> ContextModelEEPoseGoal → MLP编码
│   │   │           │
│   │   │           ├─> model.forward() - UNet去噪
│   │   │           │   └─> TemporalUnet(x_t, t, context_emb)
│   │   │           │       ├─> TimeEncoder(t)
│   │   │           │       ├─> downs (下采样路径)
│   │   │           │       ├─> ups (上采样路径)
│   │   │           │       └─> 输出 x_recon
│   │   │           │
│   │   │           └─> loss_fn(x_recon, noise) - L2损失
│   │   │
│   │   └─> 返回 loss_dict, loss_info
│   │
│   └─> 聚合损失: train_loss_batch = sum(losses)
│
├─> 3. 反向传播和优化
│   │
│   ├─> optimizer.zero_grad() - 清零梯度
│   │
│   ├─> scaler.scale(loss).backward() - 反向传播
│   │   └─> 自动微分计算所有参数的梯度
│   │       ├─> TemporalUnet 梯度
│   │       └─> ContextModel 梯度
│   │
│   ├─> clip_grad_norm_() - 梯度裁剪（可选）
│   │
│   ├─> scaler.step(optimizer) - 更新参数
│   │   └─> AdamW 优化器步进
│   │
│   └─> scaler.update() - 更新混合精度缩放器
│
├─> 4. EMA更新（每N步）
│   └─> ema.update_model_average(ema_model, model)
│       └─> θ_ema = β * θ_ema + (1-β) * θ_model
│
├─> 5. 监控和保存（定期）
│   │
│   ├─> 训练总结 (每 steps_til_summary 步)
│   │   └─> do_summary() → 生成可视化
│   │
│   ├─> 验证 (每 steps_til_summary 步)
│   │   └─> 在验证集上计算损失和总结
│   │
│   └─> 保存检查点 (每 steps_til_checkpoint 步)
│       └─> save_models_to_disk()
│           • model_current.pth
│           • ema_model_current.pth
│
└─> 6. 检查终止条件
    ├─> train_steps_current >= num_train_steps
    ├─> early_stopper.early_stop()
    └─> 如果满足 → 结束训练
```

## 关键函数调用链

### 损失计算链
```
loss_fn()
  └─> GaussianDiffusionLoss.loss_fn()
      └─> GaussianDiffusionModel.loss()
          └─> GaussianDiffusionModel.p_losses()
              ├─> GaussianDiffusionModel.q_sample()
              ├─> apply_hard_conditioning()
              ├─> ContextModelCombined.forward()
              │   ├─> ContextModelQs.forward()
              │   └─> ContextModelEEPoseGoal.forward()
              └─> TemporalUnet.forward()
                  ├─> TimeEncoder()
                  ├─> ResidualTemporalBlock (downs)
                  ├─> ResidualTemporalBlock (ups)
                  └─> SpatialTransformer (可选)
```

### 优化更新链
```
train_loss_batch.backward()
  └─> 自动微分系统
      ├─> TemporalUnet 各层梯度
      ├─> ContextModel 各层梯度
      └─> 梯度累积到 .grad 属性

scaler.step(optimizer)
  └─> AdamW.step()
      └─> 更新所有 model.parameters()
```

## 模型状态转换

```
初始化
  ├─> model.train() - 训练模式
  │   └─> 启用 dropout、batch norm 训练
  │
  └─> model.eval() - 评估模式（总结/验证时）
      └─> 禁用 dropout、batch norm 推理
```

## 数据流转换

```
数据集 (HDF5)
  ↓
TrajectoryDatasetBspline
  ↓
DataLoader (批次)
  ↓ dict_to_device
GPU Tensor (batch_dict)
  ↓
模型输入:
  • control_points_normalized: [B, H, D]
  • hard_conds: {indices: values}
  • context_qs: [B, 2*N_joints]
  • ee_pose_goal: [B, 3, 4]
  ↓
模型处理
  ↓
模型输出:
  • x_recon: [B, H, D] (预测的去噪结果)
  ↓
损失计算
  ↓
标量损失值
  ↓
反向传播
  ↓
梯度更新
```
